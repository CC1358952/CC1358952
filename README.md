## ⭐ Featured Project

### 📉 [Credit Risk Probability-of-Default Model](https://github.com/CC1358952/credit-risk-pd-model)
End-to-end consumer credit risk model on **545,779 public Lending Club loans**, from SQL exploration to a Power BI decision dashboard.

- Built a logistic regression PD model validated out-of-time on 2015 loans (**AUC 0.679**), on par with Lending Club's own credit grade
- Removed 38 data-leakage fields and pruned multicollinear features (VIF) so every risk driver supports adverse-action reasons
- Showed that an 18% PD cutoff **cuts losses 44%** and **raises net profit 32%** vs. approving all applicants, with funding-cost sensitivity
- Generated plain-English decline explanations with a local LLM (Ollama), hand-reviewed for accuracy (**80%**)
- Built a 4-page Power BI dashboard with a live cutoff simulator (DAX what-if parameters)

**Stack:** Python (pandas, scikit-learn, statsmodels, LightGBM) · SQL (DuckDB) · Power BI · Ollama
